# Cardápio digital da pizzaria

Site estático responsivo inspirado no cardápio Nova Passos, com categorias, busca, personalização de pizzas e sacola salva no navegador.

## Executar

Abra `dist/index.html` no navegador ou sirva a pasta `dist` com um servidor HTTP estático. Não há dependências de instalação ou etapa de compilação.

## Arquivos

- `dist/index.html`: estrutura da página.
- `dist/style.css`: estilos e adaptação para celular.
- `dist/app.js`: produtos, busca, opções e sacola.

## Estado atual

O fechamento de pedidos é demonstrativo. Não envia pedidos nem cobra pagamentos. Nome, preços, fotos, área de entrega e canal de atendimento precisam ser configurados para uso real. As imagens são carregadas de endereços externos da referência.
